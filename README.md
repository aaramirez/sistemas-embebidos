# Sistemas embebidos e IoT

Computadores pequeños que miden y actúan sobre el mundo: microcontroladores, entradas y salidas, interrupciones, tiempo real, sensores, energía, los buses I2C y SPI, MQTT y LoRa, seguridad y actualizaciones remotas, de la placa a la nube.

**Ver en línea:** https://aaramirez.github.io/sistemas-embebidos/
